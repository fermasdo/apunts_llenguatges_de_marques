# 4. Validació XML: DTD i XSD

!!! info "Pendent de desenvolupament"
    Esta pàgina definix l'abast de la unitat. Els apunts i exercicis es prepararan després d'acordar-los.

## Propòsit

Convertir les regles d'un document en un contracte verificable i interpretar els errors de validació.

## En acabar podràs

- diferenciar bona formació i validesa;
- llegir i crear una DTD bàsica;
- definir estructures, tipus i restriccions amb XSD;
- preparar casos de prova vàlids i invàlids.

## Minirepte previst

Definir i provar el contracte de dades del catàleg XML.

## Guió provisional

1. Per què validar.
2. DTD com a tecnologia de llegat encara present.
3. XML Schema i tipus de dades.
4. Estratègies de prova i diagnòstic.

## Evidències d'èxit

- La mostra vàlida passa la validació.
- Les mostres invàlides fallen per la causa esperada.
- Les restriccions responen a requisits explícits.
