# 1. HTML semàntic i accessible

!!! info "Pendent de desenvolupament"
    Esta pàgina definix l'abast de la unitat. Els apunts i exercicis es prepararan després d'acordar-los.

## Propòsit

Crear documents web que expressen el significat del contingut i funcionen amb diferents dispositius i tecnologies de suport.

## En acabar podràs

- construir un document HTML complet i vàlid;
- usar una jerarquia i elements semàntics adequats;
- incorporar enllaços, imatges, taules i formularis accessibles;
- comprovar el document amb teclat i validadors.

## Minirepte previst

Crear la versió HTML accessible d'un catàleg o servei professional.

## Guió provisional

1. Anatomia d'un document HTML.
2. Text, regions, navegació i contingut incrustat.
3. Taules i formularis.
4. Semàntica, accessibilitat i validació.
5. XHTML com a context històric i comparació de regles sintàctiques.

## Evidències d'èxit

- El document és vàlid i té una estructura coherent.
- Es pot recórrer amb teclat i no depén només del color.
- Els enllaços i els controls tenen noms comprensibles.
