# 7. JSON, YAML, esquemes i APIs

!!! info "Pendent de desenvolupament"
    Esta pàgina definix l'abast de la unitat. Els apunts i exercicis es prepararan després d'acordar-los.

## Propòsit

Treballar amb formats d'intercanvi i configuració habituals en projectes actuals, i comparar-los amb XML sense confondre'ls amb llenguatges de marques.

## En acabar podràs

- representar dades amb JSON i configuració amb YAML;
- detectar errors de tipus, sagnat i serialització;
- descriure restriccions bàsiques amb JSON Schema;
- interpretar dades d'una API HTTP documentada.

## Minirepte previst

Publicar una representació JSON del catàleg i validar-la contra un esquema.

## Guió provisional

1. JSON i el seu model de dades.
2. YAML per a configuració i riscos d'ambigüitat.
3. JSON Schema.
4. Intercanvi de dades amb API.

## Evidències d'èxit

- Els fitxers es poden parsejar i validar automàticament.
- Les dades conserven identificadors i tipus coherents.
- L'elecció del format es justifica segons el context.
