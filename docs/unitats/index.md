## Criteri d'actualització

Les tecnologies exigides explícitament pel currículum es treballaran amb la profunditat necessària per assolir els RA. Les tecnologies amb menor presència professional actual, com DTD o algunes bases de dades XML natives, es contextualitzaran i es compararan amb alternatives vigents. JSON, YAML, JSON Schema, API, accessibilitat i validació automatitzada s'incorporen com a ampliacions pràctiques.

Cada unitat es desenvoluparà després d'acordar-ne exemples, activitats i eines. Pots consultar mentrestant els [reptes previstos](../reptes/index.md).
