# 3. XML i espais de noms

!!! info "Pendent de desenvolupament"
    Esta pàgina definix l'abast de la unitat. Els apunts i exercicis es prepararan després d'acordar-los.

## Propòsit

Representar documents jeràrquics amb XML ben format i combinar vocabularis sense ambigüitats.

## En acabar podràs

- crear i revisar documents XML ben formats;
- distingir elements, atributs, text i metadades;
- modelar una jerarquia de manera coherent;
- aplicar espais de noms quan conviuen vocabularis.

## Minirepte previst

Crear un catàleg XML que combine dades pròpies i metadades d'un altre vocabulari.

## Guió provisional

1. Sintaxi i arbre XML.
2. Bona formació, codificació i entitats.
3. Decisions de modelatge.
4. Espais de noms.

## Evidències d'èxit

- Un parser accepta el document.
- Hi ha una arrel única i un model consistent.
- Els prefixos i URI dels espais de noms són coherents.
