# 8. Consulta i emmagatzematge de dades XML

!!! info "Pendent de desenvolupament"
    Esta pàgina definix l'abast de la unitat. Els apunts i exercicis es prepararan després d'acordar-los.

## Propòsit

Analitzar com es guarden i consulten documents XML, i triar entre tecnologies específiques i sistemes de dades d'ús general.

## En acabar podràs

- distingir emmagatzematge natiu XML i emmagatzematge híbrid;
- emmagatzemar i recuperar XML en una base de dades relacional;
- usar un gestor XML de laboratori i formular consultes sobre una col·lecció;
- crear consultes bàsiques amb XQuery;
- justificar una tecnologia segons volum, consulta i integració.

## Minirepte previst

Importar una col·lecció XML i obtindre'n un informe mitjançant consultes reproduïbles.

## Guió provisional

1. Persistència de documents.
2. XML en sistemes relacionals i generació de documents des de dades.
3. Gestors XML natius i alternatives actuals.
4. XQuery, importació, exportació i proves.

## Evidències d'èxit

- La càrrega i les consultes es poden repetir.
- La pràctica usa un sistema real de laboratori, local o en contenidor.
- Els resultats coincideixen amb les condicions demanades.
- La decisió tecnològica inclou avantatges i limitacions.
