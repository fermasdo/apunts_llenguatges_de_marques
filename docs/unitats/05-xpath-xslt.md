# 5. XPath i transformacions XSLT

!!! info "Pendent de desenvolupament"
    Esta pàgina definix l'abast de la unitat. Els apunts i exercicis es prepararan després d'acordar-los.

## Propòsit

Seleccionar informació d'un arbre XML i transformar-la en altres documents de manera reproduïble.

## En acabar podràs

- escriure expressions XPath amb rutes, predicats i funcions;
- interpretar el context d'una selecció;
- crear transformacions XSLT bàsiques;
- comprovar l'eixida sense editar-la manualment.

## Minirepte previst

Generar automàticament un informe HTML a partir del catàleg XML.

## Guió provisional

1. Model d'arbre i context XPath.
2. Selecció, filtres i funcions.
3. Plantilles i control de flux XSLT.
4. Transformació, depuració i proves.

## Evidències d'èxit

- Les consultes seleccionen exactament els nodes demanats.
- La transformació es pot repetir amb una ordre documentada.
- L'eixida és vàlida per al format triat.
