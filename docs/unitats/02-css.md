# 2. CSS i presentació web

!!! info "Pendent de desenvolupament"
    Esta pàgina definix l'abast de la unitat. Els apunts i exercicis es prepararan després d'acordar-los.

## Propòsit

Separar la presentació de l'estructura HTML i crear interfícies llegibles, adaptables i fàcils de mantindre.

## En acabar podràs

- aplicar la cascada, l'herència i el model de caixa;
- construir distribucions amb Flexbox i Grid;
- adaptar una interfície al contingut i a la pantalla;
- conservar contrast, focus i ampliació del text.

## Minirepte previst

Dissenyar un sistema visual menut per al catàleg HTML de la unitat anterior.

## Guió provisional

1. Selectors, propietats i cascada.
2. Caixa, tipografia i variables.
3. Flexbox, Grid i disseny responsive.
4. Preferències de la persona usuària i proves.

## Evidències d'èxit

- El CSS és extern i reutilitzable.
- El contingut continua sent usable en mòbil i amb zoom.
- El focus de teclat és visible.
