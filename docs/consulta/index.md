# Consulta

Este apartat reunirà referències breus per resoldre dubtes mentre treballes. No duplicarà les explicacions completes de les unitats.

## Exemple del format de codi

Els fragments indicaran el llenguatge i seran mínims i copiables:

```xml
<article disponible="true">
  <titol>Exemple mínim</titol>
</article>
```

En XML, cada element obert ha de quedar tancat i els valors dels atributs s'escriuen entre cometes.

## Recursos inicials

- [Glossari](glossari.md): definicions breus i coherents.
- Referències de sintaxi: pendents de crear quan comencen les unitats.
- Preguntes freqüents: pendents de necessitats reals del grup.

!!! tip "Com usar la consulta"
    Busca primer el terme o la sintaxi concreta. Si necessites entendre el perquè, torna a la unitat corresponent.
