# Glossari

Un **glossari** és una llista de termes amb definicions breus. Creixerà a mesura que s'incorporen les unitats.

## Termes

- **Atribut:** informació associada a un element i escrita, habitualment, dins de l'etiqueta d'obertura.
- **Cascada:** mecanisme de CSS que resol quina declaració s'aplica quan diverses regles afecten una propietat.
- **DTD:** llenguatge que declara l'estructura i part de les restriccions d'un document XML.
- **Etiqueta:** marca sintàctica que delimita o identifica un element en llenguatges com HTML o XML.
- **Feed:** document actualitzable que distribuïx una seqüència d'entrades a aplicacions lectores.
- **Llenguatge de marques:** sistema de marques que descriu l'estructura, el significat o la presentació d'un document.
- **Namespace:** mecanisme XML que distingix vocabularis mitjançant un identificador URI.
- **Parser:** programa o component que llig una sintaxi i en construïx una representació estructurada.
- **Semàntica:** significat que un element aporta al contingut més enllà de l'aparença.
- **XPath:** llenguatge d'expressions per seleccionar nodes i calcular valors en arbres XML.
- **XSD:** llenguatge XML Schema per declarar estructura, tipus i restriccions de documents XML.
- **XSLT:** llenguatge basat en XML per transformar documents, habitualment mitjançant expressions XPath.

!!! note "Glossari en creixement"
    Només s'afegiran termes que apareguen realment en els apunts. Cada definició s'haurà de revisar en el seu context.
