# Espai de professorat

Este espai secundari queda reservat per a documentació de planificació, rúbriques i materials d'ús docent. No forma part del recorregut ordinari de les unitats de l'alumnat.

La [programació inicial](programacio-inicial.md) recull només el marc mínim necessari per justificar l'estructura. La programació formal del centre haurà d'incorporar la normativa autonòmica i les instruccions vigents que encara estan pendents de verificació.

## Abans de publicar documentació

- [ ] Identificar l'administració i el territori aplicables.
- [ ] Citar la norma i la font oficial.
- [ ] Anotar la data de consulta.
- [ ] Separar les citacions normatives de les decisions metodològiques.
- [ ] Eliminar dades personals, qualificacions i credencials.
