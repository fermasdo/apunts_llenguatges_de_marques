## Com treballarem

Cada unitat parteix d'un problema breu i proposa una seqüència clara: conceptes, exemple guiat, pràctica, diagnòstic d'errors i autoavaluació. No cal que memoritzes les instruccions: l'objectiu és entendre què fa cada element, provar-lo i comprovar el resultat.

!!! tip "Per començar"
    Entra en la [unitat 0: Punt de partida](unitats/00-punt-de-partida.md). Només necessitaràs un editor de text pla i un navegador per crear la primera pàgina web.
