# Llenguatges de Marques

Este lloc reunirà els apunts, les activitats i els recursos de consulta del mòdul 0373. L'itinerari connecta publicació web, documents estructurats, formats d'intercanvi i integració de sistemes.

## Comença ací

- Consulta la [Guia del mòdul](guia/index.md) per saber com s'organitzarà el treball.
- Accedix a les [Unitats](unitats/index.md) per seguir els apunts.
- Practica amb els [Reptes](reptes/index.md).
- Resol dubtes des de l'espai de [Consulta](consulta/index.md).

!!! info "Projecte en construcció"
    Ja està disponible l'estructura completa del curs. Desenvoluparem els apunts i exercicis unitat per unitat, amb objectius i comprovacions clares per al treball semipresencial.

## Què trobaràs

Cada unitat avançarà des d'un problema breu fins als conceptes, un exemple guiat, el diagnòstic d'errors, la pràctica i l'autoavaluació. Els reptes combinaran diverses unitats en productes pròxims a situacions professionals.
